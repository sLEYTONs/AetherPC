# AetherPC v1.0.0

First public release of **AetherPC** — free and open-source Windows optimization, diagnostics and maintenance.

## Downloads

- **AetherPC_Setup.exe** — full installer (Normal layout)
- **AetherPC_Portable.exe** — single-file portable build

## Highlights

- Home, Hardware, Monitor, Processes and Services
- Optimize and Beast Mode
- Cleanup, Drivers, History and Settings
- Spanish / English
- Light / Dark
- Installer and Portable distributions
- Self-contained builds — no separate .NET installation required

## Requirements

- Windows 10 or Windows 11 (64-bit)
- Administrator privileges are required to apply system changes

## Notes

- AetherPC applies real Windows configuration changes, so some actions may be blocked or reverted by Windows, security software or system policies.
- Beast Mode is more aggressive than Optimize and should be reviewed before applying changes.
- Verification and rollback are available when supported by the action.
