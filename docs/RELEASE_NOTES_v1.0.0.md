# AetherPC v1.0.0

First public release of **AetherPC** — free and open-source Windows optimization, diagnostics and maintenance.

## Downloads

- **AetherPC_Setup.exe** — full installer (Normal layout)
- **AetherPC_Portable.exe** — single-file portable build

## Highlights

- Home, Hardware, Monitor, Processes, Services
- Optimize and Beast Mode (confirmed apply, history / soft rollback when possible)
- Cleanup, Drivers, History, Settings
- Spanish / English and Light / Dark
- Self-contained (no separate .NET install required for these builds)

## Requirements

- Windows 10 or 11 (64-bit)
- Administrator rights to apply system changes

## Notes

- Changes to Windows are not guaranteed against antivirus or policy.
- Beast Mode is more aggressive than Optimize; review before applying.
